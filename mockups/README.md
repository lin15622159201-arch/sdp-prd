# 款式日志中心 - 样式预览

## 📁 文件说明

- **log-center-styles.html** - 日志中心完整样式预览（1008行，7个视图）

## 🎨 包含的视图

### 1. 📋 日志中心主页面
- 全局审计入口页面
- 筛选条件：款式编号、实体类型、操作大类、操作类型、操作人、时间范围、品类
- 数据表格：维度标签、款式编码、操作时间、操作人、操作内容、操作按钮
- 分页组件

### 2. 📂 操作日志抽屉
- 从款式管理列表触发的抽屉视图
- Tab 筛选：全部/字段变更/素材变更/集成事件/访问操作
- 时间线式日志列表展示
- 合并展示 SKC + SPU 的变更记录

### 3. 🗂 变更日志 Tab
- SKC 详情页内嵌的 Tab 视图
- 与操作日志抽屉共用数据展示逻辑
- 去掉款式编码列（当前上下文已明确）

### 4. 🔍 变更详情弹窗 · 字段变更
- 字段级 diff 对比表格
- 支持状态流转展示（红色→绿色）
- 新增/清空字段的特殊标记

### 5. 🖼 变更详情弹窗 · 素材变更
- 左右分栏对比
- 图片/视频缩略图展示
- 新增/删除素材的占位符

### 6. 🔗 变更详情弹窗 · 集成事件
- 事件结果横幅（成功/失败/处理中）
- 失败原因消息框
- 事件元数据展示

### 7. ⚠️ 异常状态集合
- 空状态（无数据）
- 查询超时
- 无权限访问
- 加载失败（列表、弹窗）
- 素材缩略图加载失败

## 🚀 如何使用

### 方法1：直接打开
```bash
# Windows
start d:\workSpace\mockups\log-center-styles.html

# 或双击文件用浏览器打开
```

### 方法2：本地服务器
```bash
cd d:\workSpace\mockups
python -m http.server 8080
# 访问 http://localhost:8080/log-center-styles.html
```

## 🎯 设计特点

- **设计风格**：Ant Design 5.x 风格（B端产品常用）
- **配色方案**：
  - 主色：#1677FF（蓝色）
  - 成功：#52C41A（绿色）
  - 错误：#FF4D4F（红色）
  - 警告：#FAAD14（橙色）
- **交互设计**：顶部导航栏切换不同视图
- **响应式**：固定宽度布局，适配桌面端

## 📊 标签颜色说明

| 标签类型 | 颜色 | 用途 |
|---------|------|------|
| SPU | 蓝色 | 款式维度 |
| SKC | 绿色 | SKC维度 |
| 字段变更 | 紫色 | 操作大类 |
| 素材变更 | 粉色 | 操作大类 |
| 集成事件 | 青色 | 操作大类 |
| 访问操作 | 橙色 | 操作大类 |

## 📝 基于文档

此样式预览基于 `style-log-center.md` 规格文档生成，包含：

## 🔧 技术实现

- **纯 HTML + CSS**：无需额外依赖
- **自包含**：所有样式内联在 `<style>` 标签中
- **JavaScript**：仅用于视图切换（20行左右）
- **浏览器兼容**：现代浏览器（Chrome/Edge/Firefox/Safari）
