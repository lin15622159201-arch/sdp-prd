## 1. 需求背景

### 1.1 问题描述

本版本集中解决两类问题：

1. **BOM 资料可见性问题**：款式管理和商品管理均无法查看 PLM 中的 BOM 和尺寸表，也无法展示算法推荐的面料/花型。运营和商品团队需要在多个系统之间切换才能看完整资料，效率低下。
2. **成分数据流通问题**：Temu 平台的商品属性（含成分值）在同步时未被采集，导致 PIMS 等内部系统无法直接通过 SDP 查询成分，需要单独对接 Temu 平台。

### 1.2 需求清单

| 序号 | 需求描述 | 需求类型 | 模块 | 优先级 |
|------|---------|---------|------|--------|
| 1 | 款式管理：在款式详情展示 PLM BOM，支持多版本切换 | 新增功能 | style-management | P1 |
| 2 | 款式管理：在款式详情展示尺寸表，支持多版本切换 | 新增功能 | style-management | P1 |
| 3 | 款式管理：在款式详情展示算法推荐面料和花型；**v2.8.1 新增触发时机：智能开款其他算法任务执行完成后也触发推送** | 新增功能 | style-management | P2 |
| 4 | 款式管理：新增「推荐面料」「推荐花型」布尔标签，算法服务推送值后自动置为 true，款式列表支持通过标签筛选 | 新增功能 | style-management | P2 |
| 5 | 商品管理：商品详情产品属性面料成分行新增「查看成分」入口（弹窗），弹窗查询 PLM 洗水唛成分（独立于 BOM）；尺寸表区域新增「查看尺寸」入口（弹窗），通过 SKC 实时查询 PLM | 新增功能 | temu-product | P1 |
| 6 | temu 同步商品服务：在现有同步任务中顺带获取并存储 Temu 平台属性值（含成分） | 功能优化 | temu-product | P1 |
| 7 | 调用 Temu 接口直接更新属性值：将 SDP 中的成分/属性值主动写回 Temu 平台 | 新增功能 | temu-product | P1 |

### 1.3 版本说明

本版本基于 v2.7.0 迭代，不依赖前序未上线版本。涉及模块：款式管理 (style-management)、商品管理 (temu-product)。

## 3. 模块变更详情

### 3.1 模块：款式管理 (style-management)

#### 变更概述

款式详情页新增三个展示区域：PLM BOM 资料（含多版本切换）、PLM 尺寸表（含多版本切换）、算法推荐面料和花型。均为只读展示，不支持编辑回写。同时，款式列表页新增「推荐面料」「推荐花型」两个布尔标签，算法服务有推送时自动标记，支持通过标签筛选。

**v2.8.1 关键变更**：算法推荐的触发时机在原有「开款任务正常流转」基础上，新增「智能开款的其他算法任务执行完成后也触发推送」，确保智能开款全链路的推荐结果能及时同步到款式详情。

##### 功能三：算法推荐面料和花型

**数据来源**：算法服务异步推送。

**触发时机**（以下任一事件触发后，算法更新推荐结果并推送至对应款式）：
- 开款任务正常流转
- **智能开款的其他算法任务执行完成（v2.8.1 新增）** — 本期扩展的关键触发时机，确保智能开款全链路结束后推荐面料/花型能及时更新，不再依赖开款任务流转才能触发

**展示内容**：
- 推荐面料列表（含面料图片、货号、商品类型等基础信息）
- 推荐花型列表（含花型图片、编号等基础信息）

> 本期推荐面料/花型与 BOM **分开展示**，不做关联；与 BOM 物料节点的绑定关联留待后续版本。

**筛选支持**：款式列表页标签筛选区支持按「推荐面料」「推荐花型」标签过滤，与现有标签筛选能力一致。

### 3.2 模块：商品管理 (temu-product)

#### 变更概述

商品详情页产品属性面料成分行新增「查看成分」入口（弹窗），查询 PLM 洗水唛成分（独立于 BOM，仅展示成分描述及更新日期）；尺寸表区域新增「查看尺寸」入口（弹窗），通过 SKC 实时查询 PLM；temu 同步任务顺带采集 Temu 平台属性值并存储；新增调用 Temu 接口直接回写属性值的操作入口。

#### 页面变更

#### 商品详情页 — 产品属性模块 — 修改

面料成分行新增「查看成分 ›」链接，入口固定传入第一个 SKC（正常款）。

##### 洗水唛成分弹窗 — 新增

- 入口：产品属性模块 → 面料成分行「查看成分 ›」链接
- 数据来源：PLM 洗水唛成分接口（**独立于 BOM**，非 BOM 面料明细中的成分字段）
- 关联路径：SKC 货号 → 实时查询 PLM 洗水唛成分接口
- 弹窗内容：
  - 头信息：SKC、更新日期（PLM 洗水唛成分的最后更新日期）
  - 成分列表：仅展示成分描述（每条洗水唛成分项一行）
- 只读展示，不支持编辑
- 无 BOM 版本号切换；无物料项目、图片、使用部位等 BOM 相关列

**商品详情页 — 尺寸表区域 — 修改**

尺寸表区域新增「查看尺寸」操作链接，点击后打开尺寸表弹窗。

**尺寸表弹窗 — 新增**

- 关联路径：SKC 货号 → 实时查询 PLM 接口
- 弹窗展示内容与款式管理功能二完全一致：
  - 尺寸表头信息（版本号下拉切换、提交时间）
  - 各量体部位数据（部位/尺寸精度/量法/样衣尺寸/纸样尺寸/跳码/大货尺寸各码/允差范围）
- 只读展示，不支持编辑

**异常处理**

| 场景 | 处理方式 |
|------|---------|
| SKC 未关联 PLM | 禁用「查看成分」/「查看尺寸」链接，hover 提示"暂无关联 PLM 款式" |
| PLM 接口超时或返回错误 | 弹窗内显示"资料加载失败，请稍后重试" |
| SKC 在 PLM 中不存在 | 弹窗内显示"PLM 中未查询到该款式的洗水唛成分" / "未查询到尺寸表" |
| 洗水唛成分为空 | 弹窗内显示"暂无洗水唛成分" |

---

#### 功能五：temu 同步任务增加属性值采集

**触发方式**：在现有 temu 同步商品任务中顺带拉取，不新增单独触发入口。

**采集内容**：Temu 平台的商品属性值（包含但不限于面料成分比例、材质描述等 Temu 平台定义的属性字段）。

**存储方式**：新增字段 `temu_attributes`（JSON数组），随商品同步时写入，同步时全量覆盖更新。

**字段结构示例**：
```json
[
  { "attr_id": "101", "attr_name": "面料成分", "attr_value": "100%棉" },
  { "attr_id": "102", "attr_name": "材质", "attr_value": "纯棉" }
]
```

---

#### 功能六：调用 Temu 接口直接更新属性值（v2.8.1 新增）

**触发方式**：编辑商品属性保存后，由系统自动推送。

**操作路径**：商品列表页或商品详情页，编辑属性后推送。

**执行逻辑**：
1. 取当前商品的 `temu_attributes` 中的成分相关字段
2. 调用 Temu 平台属性更新接口，将成分值写回对应商品
3. 记录回写结果（成功/失败/部分失败），展示给操作人

**异常处理**：

| 场景 | 处理方式 |
|------|---------|
| 商品无成分数据（`temu_attributes` 为空） | 禁用操作，提示"该商品暂无成分数据，请先完成 Temu 同步" |
| Temu 接口返回错误 | 提示"成分回写失败：{错误原因}"，支持重试 |

> [TBD] Temu 属性更新接口的字段映射规则（attr_id 与 Temu 平台字段的对应关系）需与 Temu 对接确认。

## 4.5 图片安全（v2.8.1 新增需求）

### 背景

各处图片展示入口依赖浏览器原生右键菜单可直接保存图片，存在资料外泄风险。本期统一收口：禁用所有图片的右键菜单，改由系统提供受控的下载/批量下载按钮，并对所有下载行为写入日志。

### 覆盖范围

以下所有区域的图片均需禁用右键保存，并提供统一下载入口：

| 模块 | 页面/区域 | 图片类型 |
|------|---------|---------|
| 款式管理 | 款式列表缩略图 | SKC 营销图（预览） |
| 款式管理 | SKC 详情页 · 营销图 / 设计图 | 营销图、设计图 |
| 款式管理 | 款式详情 · BOM 展示区（v2.8.1 新增功能） | 面料物料图 |
| 款式管理 | 款式详情 · 推荐面料/花型展示区（v2.8.1 新增功能） | 推荐面料图、推荐花型图 |
| 商品管理 | 商品列表缩略图 | SKC 素材图（预览） |
| 商品管理 | 商品详情页图片 | 素材图、款式图 |
| 商品管理 | BOM 资料弹窗（完整版/成分简版）（v2.8.1 新增功能） | 面料物料图 |

> 尺寸表弹窗无图片，不在本需求范围内。

### 交互规范

**禁用右键**：所有受控图片元素统一禁用 `contextmenu` 事件，不显示浏览器原生菜单。

**下载入口**：

- 单图：图片悬浮时显示下载 icon 或操作工具栏提供「下载」按钮
- 多图/批量：页面/弹窗提供「批量下载」按钮，打包后下载

**权限控制**：复用已有权限码 `SDP-SJZX-KSGL-XZTP`（下载图片），全局统一使用同一权限码，不区分图片类型和所属模块。

### 日志记录

图片下载日志按模块分别写入各自的日志表：

- **款式管理侧**（style-management）：写入 style-log-center（款式日志中心）
- **商品管理侧**（temu-product）：写入商品日志表（product-log-center），不经由 style-log-center

**操作类型**：复用已有的 `MEDIA_DOWNLOAD`（action_category: ACCESS）。

**扩展内容（v2.8.1 变更）**：

`event_detail` 补充 `download_scope` 字段，标识下载来源区域：

| download_scope 枚举值 | 适用日志表 | 说明 |
|----------------------|-----------|------|
| `STYLE_MARKETING_PIC` | style-log-center | 款式营销图 |
| `STYLE_DESIGN_PIC` | style-log-center | 款式设计图 |
| `STYLE_BOM_PIC` | style-log-center | 款式 BOM 物料图 |
| `STYLE_RECOMMEND_PIC` | style-log-center | 款式推荐面料/花型图 |
| `PRODUCT_MATERIAL_PIC` | product-log-center | 商品素材图/款式图 |
| `PRODUCT_BOM_PIC` | product-log-center | 商品 BOM 弹窗物料图 |

**event_detail 结构示例**（MEDIA_DOWNLOAD）：

```json
{
  "download_scope": "STYLE_BOM_PIC",
  "file_count": 3,
  "files": [
    { "file_id": "oss://...", "file_name": "fabric_a.jpg" }
  ]
}
```

### 异常处理

| 场景 | 处理方式 |
|------|---------|
| 无下载权限（缺少 `XZTP`） | 不显示下载按钮；若直接调用下载接口则返回 403 |
| 下载文件为空 | 提示"暂无可下载的图片" |
| 批量下载打包失败 | 提示"下载失败，请稍后重试" |
| 日志写入失败 | 不阻断下载主流程，后台记录失败日志支持补偿 |

### 数据模型变更

| 实体 | 变更类型 | 变更内容 | 说明 |
|------|---------|---------|------|
| style_change_log | 扩展结构 | `event_detail` 新增 `download_scope` 字段 | (v2.8.1 新增) 标识下载来源区域，便于审计 |
| product_change_log | 新增操作类型 | 新增 `MEDIA_DOWNLOAD`（action_category=ACCESS）| (v2.8.1 新增) 记录商品侧图片下载操作 |

### 依赖变更

| 变更类型 | 目标系统 | 类型 | 说明 |
|---------|---------|------|------|
| 扩展调用 | style-log-center | hard | 款式管理（style-management）图片下载日志写入 style-log-center，新增 download_scope 字段 |
| 扩展调用 | product-log-center | hard | 商品管理（temu-product）图片下载日志写入 product-log-center，新增 MEDIA_DOWNLOAD 操作类型 |
