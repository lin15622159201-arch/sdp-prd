## 1. 需求背景

### 1.1 问题描述

本版本集中解决两类问题：

1. **BOM 资料可见性问题**：款式管理和商品管理均无法查看 PLM 中的 BOM 和尺寸表，也无法展示算法推荐的面料/花型。运营和商品团队需要在多个系统之间切换才能看完整资料，效率低下。
2. **成分数据流通问题**：Temu 平台的商品属性（含成分值）在同步时未被采集，导致 PIMS 等内部系统无法直接通过 SDP 查询成分，需要单独对接 Temu 平台。

### 1.2 需求清单

| 序号 | 需求描述 | 需求类型 | 模块 | 优先级 |
|------|---------|---------|------|--------|
| 1 | 款式管理：在款式详情展示 PLM BOM，支持多版本切换 | 新增功能 | style-management | P1 |
| 2 | 款式管理：在款式详情展示尺寸表，支持多版本切换 | 新增功能 | style-management | P1 |
| 3 | 款式管理：在款式详情展示算法推荐面料和花型；**v2.8.1 新增触发时机：智能开款其他算法任务执行完成后也触发推送** | 新增功能 | style-management | P2 |
| 4 | 款式管理：新增「推荐面料」「推荐花型」布尔标签，算法服务推送值后自动置为 true，款式列表支持通过标签筛选 | 新增功能 | style-management | P2 |
| 5 | 商品管理：商品详情 SKC 列表行新增「查看 BOM」入口（弹窗），尺寸表区域新增「查看尺寸」入口（弹窗），均通过 SKC 实时查询 PLM | 新增功能 | temu-product | P1 |
| 6 | temu 同步商品服务：在现有同步任务中顺带获取并存储 Temu 平台属性值（含成分） | 功能优化 | temu-product | P1 |
| 7 | 调用 Temu 接口直接更新属性值：将 SDP 中的成分/属性值主动写回 Temu 平台 | 新增功能 | temu-product | P1 |
| 8 | 提供 API 供 PIMS 查询商品成分（Temu 属性里的成分值） | 新增功能 | temu-product | P1 |

### 1.3 版本说明

本版本基于 v2.7.0 迭代，不依赖前序未上线版本。涉及模块：款式管理 (style-management)、商品管理 (temu-product)。

```
PLM（外部）
  │ 按 SKC 实时查询 BOM 版本列表 + 明细

  │ 存储 temu_attributes 到商品记录
  ▼

  └─ 查询时从 temu_attributes 中提取成分字段
```

## 3. 模块变更详情

### 3.1 模块：款式管理 (style-management)

#### 变更概述

款式详情页新增三个展示区域：PLM BOM 资料（含多版本切换）、PLM 尺寸表（含多版本切换）、算法推荐面料和花型。均为只读展示，不支持编辑回写。同时，款式列表页新增「推荐面料」「推荐花型」两个布尔标签，算法服务有推送时自动标记，支持通过标签筛选。

**v2.8.1 关键变更**：算法推荐的触发时机在原有「开款任务正常流转」基础上，新增「智能开款的其他算法任务执行完成后也触发推送」，确保智能开款全链路的推荐结果能及时同步到款式详情。

#### 页面变更

##### 功能三：算法推荐面料和花型

**数据来源**：算法服务异步推送。

**触发时机**（以下任一事件触发后，算法更新推荐结果并推送至对应款式）：
- 开款任务正常流转
- **智能开款的其他算法任务执行完成（v2.8.1 新增）** — 本期扩展的关键触发时机，确保智能开款全链路结束后推荐面料/花型能及时更新，不再依赖开款任务流转才能触发

**展示内容**：
- 推荐面料列表（含面料图片、货号、商品类型等基础信息）
- 推荐花型列表（含花型图片、编号等基础信息）

> 本期推荐面料/花型与 BOM **分开展示**，不做关联；与 BOM 物料节点的绑定关联留待后续版本。

##### 功能四：推荐面料/花型布尔标签（v2.8.1 新增）

**款式列表页 — 修改**

新增两个款式标签，由算法服务推送时自动写入，不支持手动修改：

| 标签名 | 字段 | 说明 |
|--------|------|------|
| 推荐面料 | `has_recommended_fabric` | 算法服务推送了推荐面料后置为 true，否则为 false |
| 推荐花型 | `has_recommended_pattern` | 算法服务推送了推荐花型后置为 true，否则为 false |

**筛选支持**：款式列表页标签筛选区支持按「推荐面料」「推荐花型」标签过滤，与现有标签筛选能力一致。

### 3.2 模块：商品管理 (temu-product)

#### 变更概述

商品详情页 SKC 列表行新增「查看 BOM」入口（弹窗），尺寸表区域新增「查看尺寸」入口（弹窗），均通过 SKC 实时查询 PLM，展示内容与款式管理一致；temu 同步任务顺带采集 Temu 平台属性值并存储；新增调用 Temu 接口直接回写属性值的操作入口；新增对外 API 供 PIMS 查询成分。

#### 页面变更

**商品详情页 — SKC 列表区域 — 修改**

每条 SKC 行保留「价格变动历史」操作入口，查看 BOM 入口迁移至产品属性模块。

##### BOM 资料弹窗（完整版）— 新增

- 入口：商品详情页 → 产品属性模块 → 面料成分行「查看 BOM」链接，默认传入第一个 SKC（正常款）
- 关联路径：SKC 货号 → 实时查询 PLM 接口
- 弹窗内容：
  - BOM 头信息（SKC、BOM 版本号下拉切换、创建时间）
  - 面料明细 / 辅料明细 / 特殊辅料明细，三类纵向连续展示，各自带小标题，不分 Tab
- 只读展示，不支持编辑

##### BOM 资料弹窗（成分简版）— 新增

- 入口：产品属性模块 → 面料成分行「查看 BOM ›」链接，点击后默认展示第一个 SKC（正常款）
- 弹窗内容（精简）：
  - BOM 头信息（SKC、BOM 版本号下拉切换、创建时间）
  - 仅展示面料明细，且仅保留：物料项目、图片、成分、使用部位 四列
- 底部提供「查看完整 BOM」跳转到完整版弹窗
- 只读展示，不支持编辑

**商品详情页 — 尺寸表区域 — 修改**

尺寸表区域新增「查看尺寸」操作链接，点击后打开尺寸表弹窗。

**尺寸表弹窗 — 新增**

- 关联路径：SKC 货号 → 实时查询 PLM 接口
- 弹窗展示内容与款式管理功能二完全一致：
  - 尺寸表头信息（版本号下拉切换、提交时间）
  - 各量体部位数据（部位/尺寸精度/量法/样衣尺寸/纸样尺寸/跳码/大货尺寸各码/允差范围）
- 只读展示，不支持编辑

**异常处理**

| 场景 | 处理方式 |
|------|---------|
| SKC 未关联 PLM | 禁用「查看 BOM」/「查看尺寸」链接，hover 提示"暂无关联 PLM 款式" |
| PLM 接口超时或返回错误 | 弹窗内显示"资料加载失败，请稍后重试" |
| SKC 在 PLM 中不存在 | 弹窗内显示"PLM 中未查询到该款式的 BOM 资料" / "未查询到尺寸表" |
| BOM/尺寸表版本列表为空 | 弹窗内显示"暂无 BOM 资料" / "暂无尺寸表" |

#### 功能五：temu 同步任务增加属性值采集

**触发方式**：在现有 temu 同步商品任务中顺带拉取，不新增单独触发入口。

**采集内容**：Temu 平台的商品属性值（包含但不限于面料成分比例、材质描述等 Temu 平台定义的属性字段）。

**存储方式**：新增字段 `temu_attributes`（JSON数组），随商品同步时写入，同步时全量覆盖更新。

**字段结构示例**：
```json
[
  { "attr_id": "101", "attr_name": "面料成分", "attr_value": "100%棉" },
  { "attr_id": "102", "attr_name": "材质", "attr_value": "纯棉" }
]
```

---

#### 功能六：调用 Temu 接口直接更新属性值（v2.8.1 新增）

**触发方式**：编辑商品属性保存后，由系统自动推送。

**操作路径**：商品列表页或商品详情页，编辑属性后推送。

**执行逻辑**：
1. 取当前商品的 `temu_attributes` 中的成分相关字段
2. 调用 Temu 平台属性更新接口，将成分值写回对应商品
3. 记录回写结果（成功/失败/部分失败），展示给操作人

**异常处理**：

| 场景 | 处理方式 |
|------|---------|
| 商品无成分数据（`temu_attributes` 为空） | 禁用操作，提示"该商品暂无成分数据，请先完成 Temu 同步" |
| Temu 接口返回错误 | 提示"成分回写失败：{错误原因}"，支持重试 |

> [TBD] Temu 属性更新接口的字段映射规则（attr_id 与 Temu 平台字段的对应关系）需与 Temu 对接确认。

---

#### 功能七：开放 API 供 PIMS 查询成分

**接入方式**：REST API，PIMS 通过内部服务认证调用。

**接口定义**：

```
GET /api/products/{product_id}/composition
```

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| product_id | 整数 | 是 | SDP 商品 ID |

**响应结构**：

```json
{
  "product_id": 12345,
  "skc": "26060084290101",
  "temu_attributes": [
    { "attr_id": "101", "attr_name": "面料成分", "attr_value": "100%棉" }
  ],
  "synced_at": "2026-07-10T10:00:00Z"
}
```

**说明**：
- 成分数据来源为 Temu 平台属性（`temu_attributes`），非 PLM BOM 字段
- 若该商品尚未完成 Temu 属性同步，返回 `temu_attributes: []` 并附带 `synced_at: null`

---

#### 数据模型变更

| 实体 | 变更类型 | 变更内容 | 说明 |
|------|---------|---------|------|
| Product | 新增属性 | `temu_attributes`: JSON数组, 可选 | (v2.8.1 新增) 存储从 Temu 平台同步的商品属性值列表，每项含 attr_id/attr_name/attr_value；同步时全量覆盖 |
| Product | 新增属性 | `temu_attributes_synced_at`: 日期时间, 可选 | (v2.8.1 新增) Temu 属性值最后同步时间 |

#### 依赖变更

| 变更类型 | 目标系统 | 类型 | 说明 |
|---------|---------|------|------|
| 新增依赖 | PLM（外部） | soft | 商品详情 BOM 弹窗实时查询 PLM |
| 新增暴露 API | PIMS（内部） | hard | 新增成分查询接口，PIMS 依赖此接口 |
