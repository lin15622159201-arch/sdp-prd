# 规划文档 · v2.8.1 款式资料同步

> 当前日期：2026-07-08

---

## 背景

款式管理模块目前无法查看 PLM 中的 BOM 和尺寸表，也无法展示算法推荐的面料/花型。本版本补齐这两块能力。

---

## 功能范围

| # | 功能 | 来源系统 | 写入方向 |
|---|------|---------|---------|
| 1 | 款式详情展示 PLM BOM（面料/辅料/特殊辅料） | PLM | 只读，不回写 |
| 2 | 款式详情展示尺寸表 | PLM | 只读，不回写 |
| 3 | 款式详情展示算法推荐面料和花型 | 算法服务 | 只读 |

---

## 功能一：PLM BOM 展示

### 查询方式

- 按 **SKC** 实时查询 PLM 接口（不缓存 PLM 数据）
- 支持查看该 SKC 下的 **多个 BOM 版本**，版本列表按版本号倒序排列
- 用户可切换版本查看不同版本的 BOM 内容

### BOM 头信息

| 字段 | 说明 |
|------|------|
| SKC | 款式编码，如 `26060084290101` |
| BOM 版本号 | 如 `PB26060084290101-2` ，显示最新BOM版本，支持下拉切换|
| 创建时间 | 如 `2026-7-7 11:19:27` |

## 功能二：尺寸表展示

### 归属

尺寸表挂在 **款式** 下，入口在款式详情页。

### 尺寸表头信息

| 字段 | 说明 |
|------|------|
| 版本号 | 如 `SZ260405087301-4`，显示最新版本，支持下拉切换 |
| 提交时间 | 如 `2026-7-7 11:18:35` |

### 尺寸表明细

每行对应一个量体部位，列结构如下：

| 字段 | 说明 |
|------|------|
| 部位 | 后中长 / 胸围 / 腰围 … |
| 尺寸/精度 | 如 X1 |
| 量法 | 测量方式描述 |
| 样衣尺寸 | 对应尺码的样衣数值 |
| 纸样尺寸 | |
| 跳码 | |
| 大货尺寸（各码） | 2XS / XS / S / M / L / XL … |
| 允差范围 | 如 ± 1.5 |

### 版本说明

尺寸表版本独立于 BOM 版本，两者分开展示，均支持多版本切换。

---

## 功能三：算法推荐面料和花型

### 数据来源

算法服务异步推送。

### 触发时机

以下任一事件发生后，算法更新推荐结果并推送到对应款式：

- 开款任务正常流转
- 智能开款的其他算法任务执行完成--v2.8.1 新增

### 展示内容

- 推荐面料列表（包含面料图片、货号、商品类型等基础信息）
- 推荐花型列表（含花型图片、编号等基础信息）

### 与 BOM 的关系

- 本期推荐面料/花型与 BOM **分开展示**，不做关联
- 后续版本可能将推荐结果关联到 BOM 物料节点，本期不做

---

## 不在本期范围内

- 通过款式管理回写 PLM BOM 或尺寸表
- 推荐面料/花型与 BOM 的绑定关联
- BOM 或尺寸表的编辑能力
- PLM 数据本地缓存/离线查看
