## 1. 需求背景

### 1.1 问题描述

本版本集中解决图片更新任务模块的交互优化和数据完整性问题：

1. **视频/图片类型混淆**：当前任务类型为单选（图片或视频），但实际业务中需要同时更新SKC级别的图片和视频，且视频实际存储在款式管理的独立字段，与营销图分离。
2. **返修历史记录缺失**：多次返修后仅保留最新一次的返修说明，历史记录丢失，无法追溯完整的修改过程。
3. **上传操作不便**：更新内容区域无批量删除功能，只能逐个删除；修图说明仅支持单张参考图，限制了需求表达。
4. **查询能力不足**：列表页缺少 SKC 查询条件，只能通过 SPU 查询，定位具体颜色款式不便。
5. **美工协作信息缺失**：上传图片时无法记录美工备注，影响后续追溯和沟通。
6. **必填规则过严**：修图需求说明强制必填，部分场景（如简单的图片替换）无需详细说明，造成操作冗余。

### 1.2 需求清单

| 序号 | 需求描述 | 需求类型 | 模块 | 优先级 |
|------|---------|---------|------|--------|
| 1 | 视频/图片类型合并：支持同时勾选视频需求，视频为SKC维度，更新到款式管理的营销视频字段（与营销图分离），界面上分区展示 | 功能优化 | image-update | P0 |
| 2 | 保留多次返修的图片和说明记录：展示修图需求分类+图片快照+文本+处理人+时间 | 功能新增 | image-update | P1 |
| 3 | 上传图片弹窗，更新内容处增加全部删除按键 | 交互优化 | image-update | P2 |
| 4 | 列表增加 SKC 查询条件 | 功能优化 | image-update | P1 |
| 5 | 上传图片弹窗增加美工备注 | 功能新增 | image-update | P2 |
| 6 | 修图需求说明非必填 | 业务规则调整 | image-update | P2 |
| 7 | 修图需求说明支持上传多张图片 | 功能优化 | image-update | P1 |

### 1.3 版本说明

本版本基于 v2.7.1 迭代（主线版本），仅涉及图片更新任务 (image-update) 模块。

**版本依赖关系**：

3. 优化上传和创建页面交互细节
4. 扩展查询和数据记录能力

#### 页面变更

##### 需求1：视频/图片类型合并（优先级 P0）

**影响页面**：
- 第7章：发起图片/视频更新（表单字段调整）
- 第8章：创建修图任务（页面结构调整）
- 第9章：上传图片/视频（分区展示+业务规则变更）
- 第10章：审核更新结果（分区展示）

**变更详情**：

**7. 发起图片/视频更新 — 修改**

表单字段调整：

| 字段名称 | 输入方式 | 必填 | 说明（v2.8.2 变更） |
|---------|---------|------|------|
| SPU编号 | 文本输入 | 是 | 支持批量输入，确认时查询款式管理及现货管理 |
| 更新内容类型 (v2.8.2 变更) | 多选框组 | 是 | 默认选中「图片」。可选：图片 / 视频。支持同时勾选。视频为 SKC 维度，更新到款式管理营销视频字段 |
| 加急 | 开关 | 否 | 默认关闭；开启后任务列表显示「加急」标签 |

业务规则补充：
- 至少需要勾选一种类型（图片或视频）
- 同时勾选图片+视频时，后续页面分区展示

**8. 创建修图任务 — 修改**

页面结构调整：

- 当任务包含图片时，显示「图片更新区域」（原有逻辑）
- 当任务包含视频时，显示「视频更新区域」（v2.8.2 新增）
  - 左侧显示款式信息（按 SKC 切换）
  - 右侧显示视频需求说明输入框（与图片修图说明格式一致）
  - 支持上传视频需求说明参考图（最多 5 张，v2.8.2 新增）

业务规则变更（v2.8.2）：
1. 左侧显示已选中的款式信息，点击切换款式，加载对应的营销图（图片区域）或营销视频（视频区域）
2. **图片区域**：勾选对应图片，出现修图需求说明+编号
3. **视频区域**（v2.8.2 新增）：显示当前 SKC 的营销视频（如有），填写视频更新需求说明
4. ~~提交时校验：至少需要输入一个修图说明~~（v2.8.2 变更：修图需求说明改为非必填）
5. 修图说明最大输入 500 字
6. **支持上传修图说明参考图，每个说明最多上传 5 张图片**（v2.8.2 变更，原限制为 1 张）
7. 如当前选中的款式已有进行中的任务，不允许再提交

**9. 上传图片/视频 — 修改**

页面结构调整（v2.8.2）：

- 分为「图片上传区域」和「视频上传区域」（根据任务包含的类型显示）
- 图片上传区域：原有逻辑 + 以下优化
  - **更新内容区域新增「全部删除」按钮**（v2.8.2 新增，需求3）
  - **新增「美工备注」输入框**（v2.8.2 新增，需求5），长文本，最大 200 字，非必填
- 视频上传区域（v2.8.2 新增）：
  - 左侧显示款式信息（按 SKC 切换）
  - 右侧显示视频上传区域（支持拖放、粘贴），限制 1 个视频，最大 100MB
  - 显示当前 SKC 的营销视频预览（如有）
  - 更新内容区域展示已上传的视频，支持删除重新上传
  - 新增「美工备注」输入框，长文本，最大 200 字，非必填

业务规则变更（v2.8.2）：
1. 支持粘贴、拖放图片/视频进行上传
2. 左侧显示已选中的款式信息，点击切换款式，加载对应的营销图/营销视频、更新结果
3. **图片区域**：任务类型包含图片时显示
   - 需要上传 1-10 张图片
   - 支持点击保留按钮，将当前图片添加至更新内容，更新内容最大支持 10 张图
   - **更新内容区域新增「全部删除」按钮**（v2.8.2 新增），点击后清空所有已添加的图片
   - **新增「美工备注」输入框**（v2.8.2 新增），记录美工处理说明，保存到任务记录
4. **视频区域**（v2.8.2 新增）：任务类型包含视频时显示
   - 需要上传 1 个视频，最大 100MB（由原 50MB 调整）
   - 视频格式支持：mp4 / mov / avi
   - 更新内容区域展示已上传的视频，支持删除重新上传
   - 新增「美工备注」输入框，记录美工处理说明
5. 提交更新后将覆盖当前图片/视频
6. **提交时记录美工备注到任务历史记录**（v2.8.2 新增）

**10. 审核更新结果 — 修改**

页面结构调整（v2.8.2）：

- 分为「图片审核区域」和「视频审核区域」（根据任务包含的类型显示）
- 每个区域显示：
  - 左侧款式信息（按 SKC 切换）
  - 右侧对比展示：当前营销图/视频 vs 更新结果
  - **新增「返修历史记录」折叠区域**（v2.8.2 新增，需求2）

**返修历史记录展示**（v2.8.2 新增，需求2）：

- 入口：审核页面右上角显示「查看返修记录 (n)」链接，点击展开折叠面板
- 展示内容（按时间倒序）：

| 展示字段 | 说明 |
|---------|------|
| 返修批次 | 第 1 次返修、第 2 次返修… |
| 返修类型 | 图片返修 / 视频返修 |
| 返修说明 | 审核不通过时填写的返修说明文本 |
| 返修说明图片 | 审核不通过时上传的说明图片（如有） |
| 提交时图片快照 | 该次提交时的更新内容图片（多张） |
| 提交时视频快照 | 该次提交时的更新内容视频封面 + 视频链接 |
| 美工备注 | 该次上传时填写的美工备注（如有） |
| 处理人 | 该次上传操作人 |
| 处理时间 | 该次上传时间 |

- 无返修记录时，链接显示为「暂无返修记录」，点击无响应

业务规则补充（v2.8.2）：
1. 左侧显示已选中的款式信息，点击切换款式，加载营销图/视频和更新结果
2. 支持点击保留按钮，将当前图片/视频添加至更新内容
3. 更新内容最大支持 10 张图或 1 个视频
4. 审核通过：更新完成，图片/视频写入款式管理对应字段
5. 审核不通过：需要输入返修说明，最大支持 500 字；支持上传图片，最多一张；**保存返修记录到历史表**（v2.8.2 新增）
6. 创建图片更新任务时设计师取 SPU 维度，该 SPU 对应的 SKC 设计师允许操作审核
