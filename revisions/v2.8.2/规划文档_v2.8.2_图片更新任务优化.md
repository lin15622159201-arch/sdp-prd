## 1. 需求背景

### 1.1 问题描述

本版本集中解决款式营销图分组，和图片更新任务模块的交互优化问题：

1. 当前款式需要上多个店铺，需要有不同的营销图
2. 图片更新任务需要优化部分交互


### 1.2 需求清单

| 序号 | 需求描述 | 需求类型 | 模块 | 优先级 |
|------|---------|---------|------|--------|
| 1 | 视频/图片类型合并：不需要勾选需求分类 | 功能优化 | image-update | P0 |
| 2 | 保留多次返修的图片和说明记录：展示修图需求分类+图片快照+文本+处理人+时间 | 功能新增 | image-update | P1 |
| 3 | 上传图片弹窗，更新内容处增加全部删除按键 | 交互优化 | image-update | P2 |
| 4 | 列表增加 SKC 查询条件 | 功能优化 | image-update | P1 |
| 5 | 上传图片弹窗增加美工备注 | 功能新增 | image-update | P2 |
| 6 | 修图需求说明非必填 | 业务规则调整 | image-update | P2 |
| 7 | 修图需求说明支持上传多张图片 | 功能优化 | image-update | P1 |
| 8 | 营销图改为店铺维度多组：同一SKC可按店铺分别保存一组营销图；由运营发起任务并指定目标店铺（必填），美工执行上传，创建人（运营）审核；审核通过后图片写入该店铺维度的图组；保留"通用图"（无店铺绑定）兼容存量数据；**图片写入后写入操作日志，event_detail 补充 `target_store_id` / `target_store_name` 字段，标识本次更新的目标店铺维度** | 功能优化 | image-update + style-management | P0 |
| 9 | 营销图写入模式：图片更新任务在上传图片时可选「增加」（追加到图组末尾）或「覆盖」（替换整组），默认增加；工作流/选款入口固定为增加，不展示选项 | 功能优化 | image-update + style-management | P1 |

### 1.3 版本说明

本版本基于 v2.8.2 迭代，涉及图片更新任务 (image-update) 模块、款式管理模块、商品管理模块；现货管理暂不调整。

## 3. 模块变更详情

### 3.1 模块：款式管理 (style-management)

#### 变更概述（需求8直接影响）

**(v2.8.2 新增，需求8)** 为支持 SKC 营销图按店铺维度分组存储，需新增 `skc_store_material` 实体。

#### 数据模型变更

新增实体 `skc_store_material`（SKC 店铺营销图，v2.8.2 新增）：

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | 整数 | 自动 | 主键（雪花ID） |
| prototype_id | 引用 | 是 | 关联 prototype 主键 |
| design_code | 短文本 | 是 | SKC 编码，冗余存储，≤32字符 |
| store_id | 引用 | 是 | 关联店铺管理 |
| store_name | 短文本 | 是 | 店铺名称，冗余存储，≤64字符 |
| marketing_images | JSON数组 | 是 | 该店铺维度的营销图 URL 列表（1-10 张） |
| updated_at | 日期时间 | 自动 | 最后更新时间 |
| updated_by | 短文本 | 是 | 最后更新操作人，≤64字符 |
| created_at | 日期时间 | 自动 | 记录创建时间 |

唯一索引：`(prototype_id, store_id)`，同一 SKC 同一店铺只保留一条记录。

#### 页面变更

**SKC 详情页 — 营销图区域（v2.8.2 变更，需求8）**

| 区域 | 原展示方式 | 新展示方式 |
|------|---------|---------|
| 营销图 | 单组图片直接展示 | 列表形式展示多组：每行一个店铺 + 对应图组；第一行始终为「通用营销图」（无店铺） |

**展示规则**：
- 「通用营销图」始终展示在第一行，来源：`prototype_material` 表（存量兼容）
- 店铺维度营销图从 `skc_store_material` 表查询，按店铺名称排序
- 每行支持独立编辑（上传/删除），编辑权限与原营销图一致
- 无数据的店铺行不展示（按需加载）

**补充说明**
1. 店铺维度营销图的命名规则需要在图片文件名中体现店铺信息，格式为店铺名称+其他编号
2. 当前存量数据全部保持在通用分组

### 3.2 模块：商品管理 (product-management)

#### 变更概述（需求8间接影响）

**(v2.8.2 新增，需求8)** 营销图升级为店铺维度多组后，商品管理在选图、通知、推送/复制三个场景均需感知店铺维度，确保商品侧始终使用正确店铺的图片，避免图片错配。

#### 页面变更

1. **待上架 — 选择图片弹窗** `修改` — 新增「店铺」维度选择（单选，从商品所属店铺中取值）；选择店铺后，可选图组优先展示该店铺维度的营销图（`skc_store_material`），同时保留「通用」选项展示通用营销图（`prototype_material`）

2. **商品图片更新通知** `修改` — 通知触发条件收窄：仅当「通用营销图」或「与当前商品所属店铺匹配的店铺维度图组」有更新时，才向对应商品发送通知；其他店铺维度图组的更新不触发通知，避免无关推送

3. **推送待上架 / 复制商品** `修改` — 图片取用逻辑调整为：**优先取当前店铺维度营销图**（查询 `skc_store_material`，`store_id` = 当前商品所属店铺），若该店铺维度无数据或图组为空，则降级使用通用营销图（`prototype_material`）

#### 商品管理业务规则变更

| 变更点 | 原规则 | 新规则（v2.8.2） |
| ------ | ------ | --------------- |
| 待上架选图来源 | 仅展示通用营销图 | 优先展示当前店铺维度营销图；保留通用图选项 |
| 图片更新通知范围 | 任意图组更新均通知 | 仅通用图或匹配店铺的图组更新才通知 |
| 推送/复制商品图片取用 | 固定取通用营销图 | 优先取当前店铺维度图；为空时降级取通用图 |

### 3.3 模块：图片更新任务 (image-update)

#### 变更概述

本次变更聚焦交互体验和数据完整性提升

#### 页面变更

##### 需求9（营销图写入模式）

1. **上传图片/视频** `修改` — 图片上传区域新增「写入模式」单选（增加 / 覆盖，默认增加）；「增加」= 追加到目标图组末尾，「覆盖」= 替换目标图组全部图片；选择结果记录到任务的 `write_mode` 字段，每次上传均可重新选择（覆盖上次选择）
2. **工作流/选款入口** `不变` — 该入口写入通用营销图时固定使用「增加」模式，不展示写入模式选择器

##### 需求8（营销图店铺维度分组）

1. **发起图片/视频更新** `修改` — 新增「目标店铺」单选下拉（可选，从任务关联 SPU 所属店铺中选择，注意设计时作为一个标签，后面可能会支持选店铺/风格/视觉类型等等）；选择后图片将写入该店铺维度的营销图组；不填则写入通用营销图（兼容存量）；一个任务只能绑定一个店铺
2. **创建修图任务** `修改` — 左侧营销图展示来源随目标店铺切换：有目标店铺时展示该店铺维度的营销图（skc_store_material），无目标店铺时展示通用营销图（prototype_material）；美工基于对应店铺的图填写修图需求
3. **上传图片/视频** `修改` — 审核通过后图片写入目标由「全局覆盖通用营销图」改为「写入任务绑定店铺维度的营销图组（skc_store_material 表）」；无目标店铺则仍写入通用营销图（原逻辑兼容）；不影响其他店铺的营销图
4. **审核更新结果** `修改` — 审核权限由「创建人或该SPU对应SKC设计师」调整为「仅创建人（运营）」；审核通过后图片写入任务绑定店铺维度的营销图组


##### 需求1-7（图片/视频任务优化）

1. **图片更新任务列表** `修改` — 查询条件新增「SKC 编号」文本输入（支持批量，逗号分隔）；按 SKC 精确查询，任一匹配即返回任务（需求4）
2. **发起图片/视频更新** `修改` — 去掉更新内容类型（需求1）
3. **创建修图任务** `修改` — 
  a. 页面增加勾选 视频需求，勾选后出现视频需求说明；
  b. 修图需求说明改为非必填；说明参考图由单张改为最多5张（需求1/6/7）；
  c. 增加图片维度选择（需求8）
    * 顶部默认选中 通用，可批量切换至对应店铺；允许跨店铺组选择
   * 两种模式：
    **①新增**：如果当前款式没有对应店铺的图片，支持选择其他店铺的图片，修改后将结果保存到对应店铺的图组；
   **②编辑**：如果当前款式已经有图片，修改后将结果更新到对应的店铺

4. **上传图片/视频** `修改` — 分为图片上传区域和视频上传区域；图片区域更新内容新增「全部删除」按钮；新增「美工备注」输入框（长文本，最大200字，非必填）；视频区域支持上传1个视频（需求1/3/5）

5. **审核更新结果** `修改` — 分区展示图片/视频审核区域；审核页右上角新增「查看返修记录 (n)」链接，展开折叠面板按时间倒序显示每次返修记录（返修批次/类型/说明/说明图片/提交内容快照/美工备注/处理人/时间）（需求1/2）

#### 业务规则变更汇总

| 变更点 | 原规则 | 新规则（v2.8.2） |
