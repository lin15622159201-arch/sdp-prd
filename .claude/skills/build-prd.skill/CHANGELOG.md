# Changelog

## v1.1 (2026-05-19)

- 新增文档管理工作流章节：规划中 → 开发中 → 已上线三阶段生命周期
- 新增版本目录规范：`modules/vX.Y.Z/` 仅存放变更模块，viewer 自动 fallback 到基线
- 新增 `_module-list.md` 索引文件：每次更新具体功能模块时记录模块标题到版本目录
- 更新阶段 3（执行修改）：先创建版本目录，在版本目录中修改而非直接改基线
- 更新阶段 4（汇总修改）：增加"本版本涉及的模块"清单，同步 `_module-list.md`
- 更新 `references/文档目录.md`：补充版本目录规范、加载优先级、生命周期操作表
- 修复 prd-viewer 兼容性：受影响模块表格和模块变更标题强制使用 `{模块名} (module-key)` 格式，防止被误判为"新增"模块
- prd-viewer 重构：`extractModuleRefs` 改为以 Section 6 变更汇总表的 `变更类型` 列为唯一权威字段，Section 3/4 标题仅作 fallback，移除脆弱的 `newRowRe` 和 `bareKeyRe` 正则
- 新增「撰写铁律」7 条规则：异常处理嵌入页面、禁止代码映射、业务流程前置、更新记录就近+版本号三段式、新增字段完整定义、需求规格说明书定位
- 更新 `references/文档结构.md`：章节结构约束、数据模型表扩展为 6 列（属性/类型/必填/默认值/长度范围/说明）、更新记录格式规范、完整性检查清单补充
- 更新 `references/通用设计语言规范.md`：数据属性类型表增加「必填字段」列，明确每种类型的约束要求
- SKILL.md Phase 3 验证增加结构合规 checklist，工作风格改为 7 条铁律

## v1.0 (2026-04-02)

- 初始版本
- 4 阶段迭代规划流程：需求拆解 → 影响分析 → 修改方案 → 执行更新
- 基于依赖传播链的影响分析（前向追溯 + 后向追溯）
- 规划文档模板与模块文档结构模板
- 通用设计语言规范（页面类型、交互形式、字段类型标准）
- 自检与待完善清单
- 支持 Claude Code skill 集成和任意大模型通用 prompt
