# build-prd — B端 PRD 迭代规划

> **已有模块文档，现在要改点什么？build-prd 帮你分析影响、输出规划、执行更新。**

产品迭代中最容易出问题的不是"想不清楚要做什么"，而是**"改了 A 模块，忘了通知依赖它的 B 和 C"**。每次变更都是连锁反应——字段改了，下游模块的数据模型要同步；状态机改了，依赖方的触发条件也要跟着变。

build-prd 解决的就是这个问题。你描述需求变更，AI 自动遍历现有模块文档，分析依赖传播链，生成规划文档，然后逐模块执行更新。**让每一次变更都有迹可循。**

## 与 create-prd 的区别

| | create-prd | build-prd |
|------|-----------|-----------|
| **场景** | 从零开始构建PRD | 已有模块文档的迭代 |
| **重点** | 需求价值——"为什么做" | 功能规格——"做什么" |
| **输出** | 完整14章PRD文档 | 规划文档 + 模块文档增量更新 |
| **核心能力** | 结构化生成、产品定型 | 依赖分析、影响传播、联动更新 |

> 简单说：需要从零开始构建 PRD 用 create-prd，需要说明要做什么/怎么改用 build-prd。

## 核心流程

```
你描述需求变更
    │
阶段 0: 拆解需求 → 输出需求清单 → 等你确认
    │
阶段 1: 排查影响 → 遍历模块文档，分析依赖传播链 → 输出影响分析
    │
阶段 2: 输出方案 → 逐模块给出具体修改方案 → 等你确认
    │
阶段 3: 执行修改 → 创建 modules/vX.Y.Z/ 版本目录，只拷贝变更模块，在版本目录中修改
    │
阶段 4: 汇总变更 → 输出变更汇总，更新 _module-list.md 记录模块标题
```

### 文档管理生命周期

```
规划中 → 开发中 → 已上线
  │         │         │
  │   创建版本目录   合并到基线
  │   拷贝变更模块   归档版本目录
  │   在版本目录修改
```

每个阶段都等用户确认再继续，不会自说自话改文档。基线模块文档（`modules/`）只在版本上线时才更新。

## 快速开始

### 方式一：任意大模型（不需要安装任何工具）

1. 下载 [`dist/build-prd-universal-prompt.md`](dist/build-prd-universal-prompt.md)
2. 打开你常用的大模型（ChatGPT、Gemini、DeepSeek、Kimi、通义千问等均可）
3. 先粘贴 prompt 内容，再提供你的需求描述和现有模块文档
4. AI 按 4 阶段流程输出规划文档

### 方式二：Claude Code 集成

```bash
python scripts/install_skill.py
```

安装后直接使用：

```text
/build-prd 在款式管理模块中增加批量审核功能
```

或者自然语言触发：
- "我要在订单模块加一个退款审批流程，帮我规划一下"
- "品类字典要从三级改成四级，分析下影响范围"

## 输入要求

- **需求描述**：要改什么，为什么改
- **需求所属版本号**
- **已有模块文档目录**（按 [文档目录](references/文档目录.md) 结构组织）

## 输出产物

1. **规划文档**（按 [规划文档结构](references/规划文档结构.md) 格式），存储在 `revisions/` 目录
2. **更新后的模块文档**，含版本号递增、更新记录表格

## 与 check-prd 形成闭环

| 环节 | 工具 | 作用 |
|------|------|------|
| 规划 | **build-prd** | 分析变更影响，输出规划文档，更新模块文档 |
| 审查 | **check-prd** | 用 14 维度逐项检查更新后的文档质量 |

## 仓库结构

```text
SKILL.md                        # Claude Code skill 入口
references/
├── 规划文档结构.md              # 规划文档的章节模板
├── 文档结构.md                  # 模块文档结构模板和完整性检查清单
├── 文档目录.md                  # 多文档管理目录结构
├── 通用设计语言规范.md          # 页面类型、交互形式、字段类型标准
└── appendices/
    ├── build-prd-appendix-typing.md    # 需求定型与影响分析策略
    └── build-prd-appendix-selfcheck.md # 自检与待完善清单
scripts/
├── build.py                    # 构建 universal prompt
└── install_skill.py            # 安装为 Claude Code 技能
dist/
└── build-prd-universal-prompt.md  # 独立可用的完整 prompt
```
